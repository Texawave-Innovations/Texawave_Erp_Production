Role: Chart of Accounts (COA) master catalog. Stores hierarchical ledger accounts across 5 primary types (ASSET, LIABILITY, EQUITY, REVENUE, EXPENSE).

Columns (16): id (PK), organization_id (FK), account_code (Unique per org), account_name, account_type, account_subtype, parent_account_id (FK $ o$ accounts, SET NULL), currency, opening_balance, current_balance, is_reconciled, is_active, description, created_by, created_at, updated_at.

3. Cross-Schema Integration & Foreign Keys Audit Domain Boundary Architecture

The TexaWave database uses PostgreSQL schemas (platform, crm, scm, hr, finance) to enforce clean service boundaries. Below is the verified relational map of cross-schema foreign keys:

Cross-Schema Constraints Detail
• Tenant Isolation (platform.organizations): Exactly 11 explicit foreign key constraints link each Finance table's organization_id to platform.organizations(id) with ON DELETE RESTRICT ON UPDATE CASCADE.
• Customer Linkage (crm.accounts): finance.payments_received.customer_id references crm.accounts.id with ON DELETE SET NULL, preserving historical customer names even if CRM records change.
• Supplier Disbursements (scm.supplier_payments): finance.payments_made.scm_supplier_payment_id has an explicit 1:1 unique foreign key to scm.supplier_payments.id with ON DELETE SET NULL.

4. Financial Reporting Engine Architecture Dynamic Runtime Aggregations

A critical architectural finding of this audit is that Financial Reports do not have dedicated physical database tables or materialized views. Instead, FinancialReportsService calculates all figures dynamically from the base physical tables:

Report Calculation Formulas
• Trial Balance: Aggregates net debits and credits across all active accounts from journal_lines where journal_entries.status = 'POSTED'. Verifies $sum ext{Debits} = sum ext{Credits}$.
• Balance Sheet: Groups accounts by account_type (ASSET, LIABILITY, EQUITY) up to target asOfDate. Dynamic net profit from P&L is added into Retained Earnings.
• Profit & Loss: Computes Net Operating Margin = Revenue minus Expenses over the selected period.
